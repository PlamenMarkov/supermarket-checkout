# Supermarket checkout
A Symfony based app for checkout with product promotions and admin panel

## How to run locally

1. Start containers:
    ```
    docker-compose up --build -d
2. Visit http://localhost:8080/

#### P.S. To inspect the DB schema you can visit http://localhost:8081/
